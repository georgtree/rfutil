::rfutil

RF network parameter utilities

rfutil calculates two-port S, Z, Y and scattering-transfer parameters, equivalent T/pi circuit elements, matrix products and inverses, and fixture de-embedding. It also calculates complex magnitude and phase.

Requirements

List operation requires Tcl 8.6 or Tcl 9, Tcllib (math::complexnumbers, math::constants), and argparse 0.58 or later. Vector operation additionally requires Tcl 9 and rbc::vector 0.8.5 or later. Use a current RBC build including complex vectors and vector expr -name. No Tk initialization, display or Cairo is required.

Representations and defaults

A matrix is a dictionary with keys 11, 12, 21 and 22. Each component contains a frequency sweep, not a single matrix element. In list mode, each value is a list of complex {real imag} pairs. In vector mode, each value is an RBC vector name. Complex and real parameter vectors are accepted; matrix outputs are complex. Frequency vectors must be real. Equivalent capacitance/inductance, magnitude and phase outputs are real.

Every numeric input of a call follows -input, including its frequency argument. The optional z0 remains a single {real imag} scalar in both modes. Mixed list/vector components within one call are not supported.

package require rfutil 0.2
set s [dict create 11 {{0.1 0.2}} 12 {{0.02 0.01}} 21 {{0.8 -0.1}} 22 {{0.2 0.1}}]
set z [rfutil::s2z $s]

# Convert the result into named complex vectors.
set zv [rfutil::s2z $s -output vector -namespace ::network::z -names {11 z11 12 z12 21 z21 22 z22}]
# Calculate a whole sweep using RBC expressions, returning lists.
set sAgain [rfutil::z2s $zv -input vector -output list]

The options are independent: list/list uses the Tcllib backend; vector/list and vector/vector use whole-sweep RBC expressions; list/vector uses the scalar backend and converts its final results. Keep data in vectors across successive transformations to avoid repeated list conversion.

rfutil::configure supports all-settings queries, single-option queries, and atomic updates:

set saved [rfutil::configure]
rfutil::configure -input vector -output vector -ifexists replace
rfutil::configure -output
rfutil::configure {*}$saved

Defaults are -input list, -output list and -ifexists error. Per-call options override them. Selecting vector defaults checks that RBC can be loaded. Ordinary list calls and list-default queries do not load RBC.

Naming and ownership

Input names resolve in the caller’s namespace, then through Tcl command resolution. Literal vector names with parentheses are supported. Inputs are borrowed, never destroyed or modified by calculations unless explicitly chosen as replacement destinations. Read-only inputs and nonzero index offsets are accepted.

For vector output:

  • -namespace selects the output namespace, relative to the caller, creating missing parents. An empty name is an error.

  • -names maps result fields to exact vector names. Matrix fields are 11, 12, 21, 22; equivalent-circuit fields are z1/z2/z3, y1/y2/y3, c1/c2/c3 or l1/l2/l3.

  • mag and angle accept -name for their sole output, or the result field of -names, but not both.

  • Omitted destinations use RBC’s #auto mechanism. A final #auto component is also supported explicitly.

  • Fully-qualified destinations override -namespace; their parent namespace must already exist.

  • -ifexists error rejects existing commands. replace reuses writable RBC vectors of the required numeric type, preserving their identity. It never replaces arbitrary Tcl commands.

Unknown fields, duplicate destinations, read-only outputs and type mismatches are rejected before output writes. Calculations complete before publishing, so destinations may alias inputs. Internal vectors are cleaned up on success and error; returned vectors belong to the caller and must be destroyed when no longer needed. Callbacks triggered by replacing vectors can have their own side effects; multiple destination updates are not a transaction against arbitrary user callbacks. Namespaces created for output are not removed on failure.

set magnitude [rfutil::mag [dict get $zv 11] -input vector -output vector -name ::network::magnitude]
rbc::vector destroy {*}[dict values $zv] $magnitude

Numerical scope

All input components and participating matrices must have equal lengths, including any frequency input. The caller must ensure that sample frequencies correspond; the package does not interpolate or store a frequency grid. Empty sweeps return empty components. The vector backend rejects exactly zero conversion denominators, determinants and required frequency/reactance divisors before publishing results. Nearly singular data can still amplify numerical errors; no automatic regularisation is performed.

The scalar reference impedance is common to both ports. The default reference impedance is {50.0 0.0}.

Build, test and documentation

./configure --with-tcl=/path/to/tcl/lib --prefix=/your/prefix
make
make test
make test-vector
make doc
make install

make test runs the original tests and extensions, skipping RBC-specific tests if RBC is unavailable. make test-vector requires RBC and fails if it cannot load it. TESTFLAGS is forwarded to tcltest, for example make test TESTFLAGS='-match vector.s2z.*'. A failing test or test-file error causes a nonzero exit status. Use TCLLIBPATH to supply dependencies not installed in the selected interpreter’s search path.

Documentation is generated from these Ruff sources and public procedure comments, first to Sphinx/RTD HTML and also to nroff. Install Ruff, Tcllib and Python packages sphinx and sphinx_rtd_theme; select Python with make doc DOC_PYTHON=/path/to/python. Generated HTML is in docs/index.html; the manual page is docs/rfutil.n. Out-of-source builds put generated documentation in their own docs directory.

make install supports DESTDIR; documentation is installed if already generated. make uninstall removes the installed package files and generated manual. make clean removes generated docs while retaining Ruff sources and the maintained stylesheet. make dist and make dist-zip produce complete source archives, including the pre-generated configure script, tests and documentation sources. Neither archive bundles external dependencies.

Commands

angle

Calculates angle (phase) of complex number.

angle data ?-deg? ?-input list|vector? ?-output list|vector? ?-ifexists error|replace? ?-namespace name? ?-name name?
angle data ?-deg? ?-input list|vector? ?-output list|vector? ?-ifexists error|replace? ?-namespace name? ?-names dictionary?

Parameters

-deg:

Option to select angle in degrees units.

-ifexists error|replace:

Collision policy. Replacement requires a writable vector of the same type.

-input list|vector:

Input format; defaults to ::rfutil::configure -input.

-name name:

Single destination; conflicts with the result entry of -names.

-names dictionary:

Result field to destination name mapping. Missing fields use #auto.

-namespace name:

Output namespace, created if missing; relative to the caller.

-output list|vector:

Output format; defaults to ::rfutil::configure -output.

data:

List with complex data in form {real imag}

Return value

list of angles. With vector output, returns a real RBC vector name.
